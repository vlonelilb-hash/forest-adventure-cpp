 Forest Adventure

A simple text-based adventure game built in C++.

## 📖 About

Forest Adventure is a beginner-friendly C++ game where the player wakes up
in a mysterious forest and must choose between entering a house or a cave.

Each choice leads to a different outcome. The player can find coins, lose
health, or encounter a bear.

## 🎮 How to Play

When the game starts, you have two choices:

1. Enter the house
2. Enter the cave

### 🏠 House

If you enter the house, you find a treasure chest.

You can:

- Open the chest and receive 100 coins
- Leave the house safely

### 🐻 Cave

If you enter the cave, you encounter a bear.

You can:

- Run away and lose 20 health
- Fight the bear and lose the game

After each game, you can choose whether to play again.

## 💻 Concepts Used

This project demonstrates basic C++ programming concepts:

- Variables
- `if`, `else if`, and `else`
- `do-while` loops
- User input with `cin`
- Output with `cout`
- Arithmetic operators
- Comparison operators
- Logical operators
- Basic game logic
